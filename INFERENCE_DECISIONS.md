- **Private test, runtime-oriented candidate:** final4 Q4 with adaptive **15-second total-time budget** and a six-action-turn cap; stop after a successful `sys.ask_missing_info`. The budget includes cached per-task PhoWhisper main/history inference time plus cumulative Qwen request latency. Start each sample with thinking on; before each later request, turn it off once ASR + prior Qwen latency reaches 15s. The final5 20k adapter has been screened on enriched pilot60 but did not beat final4 by point estimate; full-val and target-GPU validation remain pending.
- “Full thinking” means fixed `think: true` on every request; it is not a separately configured reasoning-depth value.
